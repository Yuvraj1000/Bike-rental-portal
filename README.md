# 🚲 Ride Hub — Bike Rental Portal

**Ride Hub** is a modern, responsive bike rental portal designed for easy bike discovery and booking. The project focuses on **HTML5, CSS3, responsive design, and basic JavaScript interactions**, featuring bike stations, bike selection, booking flow, light/dark mode, and a clean user-friendly interface. Built as an academic project for **Front End Engineering-II (25CSE0203)** by **Team Triple Joint — G12-PID-23** at Chitkara University.
